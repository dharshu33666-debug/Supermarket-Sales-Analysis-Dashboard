About Project

This project focuses on analyzing supermarket sales data to understand business performance, product sales, profitability and customer behavior.

The dashboard presents interactive visualizations for category-wise sales, profit analysis, monthly sales trends and customer segmentation.

Tools & Technologies: Python, Pandas, Flask, HTML, CSS, JavaScript and Chart.js.

Project Type: Data Analyst Project
